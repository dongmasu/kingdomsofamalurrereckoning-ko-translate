# `game` Wording Review (D-19568)

- Date: 2026-10-12.
- Scope: default ID 110 (D-043).
- Decision: **accepted**.

English says, “The game has no end in sight.” Chinese preserves `游戏`;
German, Spanish, and French explicitly say the game is not ending soon or
has no end in sight. Italian describes an ongoing `sfida` (challenge), also
not a war. Japanese alone changes the referent to `戦い` (battle), which the
Korean draft followed as `전쟁`. With English as the semantic anchor, change
only `전쟁` to `게임`; retain the rest of the sentence. The official Korean
manual's pages 1 and 8 discuss the game setting and dialogue system but do
not alter this lexical decision. No PAK or PAK-derived material was used.
