# D-20390: Allestar, Eagonn, and Gossamer End

Date: 2026-10-15

## Scope and Decisions

Reviewed three English-indexed name families across all active resources,
with five glossary entries including the distinct Tower/Glade compounds.
The exact source-aligned scope is 124 distinct active rows: 13 `base` and
111 `default`, no `affix`. The per-name row counts overlap:

| English name | affix | base | default |
| --- | ---: | ---: | ---: |
| Allestar, including Tower/Glade | 0 | 2 | 53 |
| Eagonn, including possessives/titles | 0 | 9 | 43 |
| Gossamer End | 0 | 2 | 15 |

These are actual parsed rows, not the provisional counts in the previous
session summary. All 124 rows have a disposition in
[the comparison manifest](proper-name-edits-D20390.tsv): 95 changed `Texto`
cells and 29 unchanged rows. Changes: 11 `base`, 84 `default`.

- `알레스타(Allestar)` follows the previously supported D-1230/D-6160
  spelling and the research-location identity in English. Japanese
  `アリスター` and Chinese `艾勒斯达` consistently identify the same place.
  Distinct compounds use `알레스타 탑(Allestar Tower)` and
  `알레스타 숲속 빈터(Allestar Glade)`. English `Glade` governs the
  clearing meaning; Japanese `湿原` is not adopted over English. Existing
  standalone `default` 33347 already supplies `숲속 빈터`.
- `이곤(Eagonn)` is corroborated by Japanese `イーゴン`, Chinese `伊贡`,
  and repeated English lineage/weapon narratives: Eamonn's son and
  Caerwyn's father (`default` 12597/40361/57612). Existing `이건`, `에아곤`,
  `에이곤`, `에이건`, `이아곤`, `이고언`, `이가온`, `에곤`, and `이고넌`
  are standardized only in the source-identified person's contexts.
  The demonstrative `이건` at `default` 42993 remains unchanged.
- `고서머 엔드(Gossamer End)` names the player home in Canneroc, supported
  by English housing/upgrading context, Japanese `ゴッサマー・エンド`,
  Chinese `蛛丝终焉`, and the existing `base` 3325 form. Do not translate
  this place as `고사머의 끝` or normalize generic textiles as this place.
  Nine additional generic `gossamer` rows (one `base`, eight `default`)
  are outside the place-name scope: base 4470; default
  11056/19570/22640/33995/61144/61174/62222/63238. These are not
  included in the 124-row name scope.

The official Korean manual's setting introduction (PDF pp. 1/3) and
faction/quest context (p. 7) were consulted. It supplies no exact Korean
form for these three names; source context and accepted project spelling,
not a manual no-hit, support the decisions.

The full bilingual name is repeated for each explicit named mention in
these reviewed rows. Other names in the same sentences remain outside
this batch and are not implicitly approved. Particle `으로` becomes `로`
after `숲속 빈터` at `default` 51932.

No historical terminal disposition was reopened or added to a global
tally. Sequential review remains complete through D-20377 / ID 65134.
The broader glossary pass is incomplete. Next focused review: D-20391.
