## Decisions

  location for remaining valuables are both retained.

  고통`. English describes pain being caused, not only future pain; Chinese
  supports the ongoing reading.
- ID 18214 remains uncertain: original Japanese explicitly marks Almain
  Sojourner as a vessel, while Chinese reads it as an Almain wanderer and the
  Korean form is a common-noun interpretation. Related shipwreck evidence is
  suggestive, but a corpus-wide canonical rendering is unresolved.

  to the wanderer, supporting `들어오너라, 방랑자여`.
- ID 18222 is `not an issue`: restoration of the paintings and completion of
  the gallery are retained; the remaining concern is broader place-name
  consistency, not a demonstrated meaning error.
- ID 18223 is accepted: remove the surplus literal quotation pair around
  `승리의 경기(Victory Games)`. The English, original Japanese, and Chinese
  each delimit the name once. The active CSV's doubled quote characters are
  CSV escaping for one literal quote per side.
- ID 18224 is `not an issue`: the completed choice and the speaker's view
  that further comments cannot change it are preserved.
- ID 18227 is `not an issue`: the line retains that the listener is the first

- ID 18231 is `not an issue`: the report of no remaining problems after
  Bruten was dealt with is preserved.
- ID 18237 is accepted: add `내` before `형제` to restore English `my brother`
  without importing Japanese's unsupported older-brother distinction.
- ID 18241 is `not an issue`: Korean's `모금함` reading is supported by the
  original Japanese reference to fundraising and Chinese's donation reading.
- ID 18249 remains uncertain: English `wield` and Japanese `equip` differ
  from Chinese's “swing/dance” wording. Korean's `휘두르기` may be too narrow,
  but the best player-facing action label cannot be settled from this row.
