## Installation

1. Extract the ZIP.
2. Run `RunKoreanPatch.bat` and follow the installer prompts.
3. Select `Chinese Simplified` in Steam after applying the patch; the internal
   locale remains `zh_cn`.

The ZIP is a delta for the user's existing game archive, not a standalone PAK.
