# Glossary

`proper-name-glossary.tsv` is the current proper-name reference.
`proper-name-occurrences.tsv` links candidate source occurrences to IDs and
records their dispositions. The occurrence index is scoped to its recorded
discovery process and is not an exhaustive inventory of all game terms or
names.

The old `work/zh_cn/audit/` paths remain compatibility links for existing
review scripts. Dated candidate reports and review evidence stay in the
audit directory.
